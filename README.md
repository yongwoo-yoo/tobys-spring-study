# 토비의 스프링 3.1 — 완전 초심자 학습 패키지

이 폴더는 [Incheol's TECH BLOG의 토비의 스프링 3.1 요약](https://incheol-jung.gitbook.io/docs/study/tobys-spring)을 처음부터 이해하기 위한 학습 교재다. 원문을 짧게 다시 요약하는 대신, 원문에서 생략된 배경지식과 개념 사이의 연결을 보충했다.

## 가장 먼저 알아둘 점

- 링크의 자료는 **토비의 스프링 3.1 전체 책이 아니라 일부 장의 요약**이다.
- 포함 범위는 1권 1~6장·8장, 2권 5장 일부·6장 일부다. 1권 7장 등은 제공된 사이트에 없다.
- Spring 3.1, XML 설정, JUnit 4 중심의 오래된 예제가 포함된다. 지금 그대로 복사해 실행하기보다 **설계 원리와 문제 해결 과정**을 익히는 자료로 사용한다.
- 이 자료에서 가장 중요한 질문은 “애노테이션을 어떻게 쓰나?”가 아니라 **“무엇이 왜 분리되고, 누가 객체를 만들고 연결하며, 그 결과 무엇이 쉬워지는가?”**다.

## 읽는 순서

1. [전체 지도](./00-learning-map.md): 20분 안에 전체 구조를 먼저 본다.
2. [선수지식](./01-prerequisites.md): Java·객체지향·DB 지식이 없다면 여기부터 읽는다.
3. [1권 핵심 해설](./02-volume1-core.md): 1~6장과 8장을 문제 → 리팩터링 → 원리 순서로 공부한다.
4. [2권 AOP·테스트 컨텍스트](./03-volume2-aop-test.md): 프록시 AOP, LTW, 테스트 컨텍스트를 연결한다.
5. [회상 워크북](./04-recall-workbook.md): 책을 덮고 답하면서 장기기억으로 만든다.
6. [용어 사전](./05-glossary.md): 모르는 말이 나올 때만 찾아본다.
7. [학습 기록지](./06-study-log.md): 회독과 오답을 관리한다.

## 추천 학습법

각 단원은 다음 순서로 진행한다.

1. **미리 보기(5분)**: 제목, 핵심 질문, 개념 연결만 훑는다.
2. **이해(30~60분)**: 코드를 손으로 따라가며 “이 코드의 변경 이유”를 한 문장으로 적는다.
3. **닫고 설명(10분)**: 자료를 보지 않고 회상 질문에 말로 답한다.
4. **작은 구현(20~60분)**: 제시된 실습을 직접 작성한다.
5. **간격 복습**: 다음 날, 3일 뒤, 7일 뒤, 14일 뒤에 틀린 질문만 다시 답한다.

한 장을 완벽히 외운 뒤 넘어가려 하지 말자. 1회독에서는 이야기의 흐름, 2회독에서는 코드의 책임, 3회독에서는 개념 간 연결을 잡으면 된다.

## 이 자료 전체를 관통하는 한 문장

> 스프링은 평범한 Java 객체가 비즈니스 책임에 집중하도록, 객체 생성과 연결 및 반복적인 기술 책임을 외부에서 제공하는 프레임워크다.
